M RAKESH / COMPUTATIONAL LAB

Interactive Algorithm Lab

Six interactive experiments in AI, algorithms and spatial computing.

Source code · LinkedIn · GitHub

01 / AI Tic Tac Toe

Play X against an optimal Minimax opponent. Worst-case search: O(b^d).

02 / Maze Pathfinder

Compare BFS, DFS and A* on an unweighted grid. Click cells to toggle walls.

03 / Sudoku Solver

Backtracking explores valid assignments recursively. Worst case: O(9^m), for m empty cells.

04 / Binary Decoder

Convert space-separated 8-bit ASCII values to text.

05 / SPATIAL COMPUTING

Architectural Floor Plan

Find a route between rooms in a simplified building grid. This is an educational model, not an evacuation design tool.

BFS · O(V + E) time and O(V) space
06 / MACHINE LEARNING

Neural Network Visualizer

Explore a fixed 2–2–1 neural network with sigmoid activations. Adjust inputs to observe forward propagation.

Fixed illustrative weights; no training or real prediction.
